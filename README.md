# 100 Days of Python 🐍

My journey through **[100 Days of Code: The Complete Python Pro Bootcamp](https://www.udemy.com/course/100-days-of-code/)** by Dr. Angela Yu — 100 days, 1 project per day, going from beginner to professional Python developer.

## About the Course

A 60+ hour bootcamp covering:
- Python scripting, automation, and game development
- Web scraping (BeautifulSoup, Selenium, Requests)
- Data science (Pandas, NumPy, Matplotlib, Plotly, Scikit-learn)
- GUI desktop apps (Tkinter, Turtle)
- Front-end web dev (HTML5, CSS3, Bootstrap)
- Back-end web dev (Flask, REST APIs, databases, authentication)
- Git, GitHub, and version control

## Daily Workflow

1. Create a new folder for the day (`dayN`)
2. Add a Python file inside it (`main.py`)
3. Write and test that day's project
4. Update the Progress Log table above
5. Commit and push:

git add .
git commit -m "Day N: [project name]"
git push
